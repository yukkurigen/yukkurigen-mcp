# 場面の演出（登場・退場・立ち位置／キャラの動き／背景の動き／場面転換／アイキャッチ）

テンプレートを編集する必要はない。**台本の行に書く。** どれも任意で、書かなければ以前と同じ見た目のまま。
作ったあとも `update_lines` / `insert_lines` / `split_line` で足せる・外せる（`null`）。どれを変えても音声は消えない。

## 行に書く項目

| 項目 | 何が起きるか | 引き継ぎ |
|---|---|---|
| `stage` | その行から舞台に立つキャラの並び。外したキャラは退場、加えたキャラは登場（外側へ・外側から約0.3秒ですべる）。要素を `{id, x, y, scale, facing}` にすると書いた所に立つ（下） | 次に `stage` を書いた行まで（位置も一緒に） |
| `backgroundMotion` | 背景のゆっくりした動き。`none`（既定）/ `zoomIn` / `zoomOut` / `panLeft` / `panRight`。その背景が出ている間をかけて最大8% | 次に書いた行まで（全体なら1行目に） |
| `transition` | その行での場面転換。`dissolve`（既定・0.6秒で溶かす）/ `fadeBlack`（暗転）/ `cut` | その行だけ |
| `eyecatch` | その行の前に挟む全画面の章タイトル。`"見出し"` か `{title, subtitle}` | その行だけ |
| `action` | その行の頭でキャラが1回する動き（下）。`"jump"`（話者）か `{type, target}`（target のキャラ）、配列で複数 | その行だけ |
| `offstage` | `true` でその行の話者は声だけ。その台詞では舞台に出てこない（既に居れば残る。下げるなら同じ行の `stage` から外す） | その行だけ |

- `stage` に書けるのは**台本で話すキャラだけ**（ほかは `400 validation_error`）。台詞のある行の話者は、並びに無くても自動で登場し、以後も残る（`offstage: true` の行の話者は登場しない）
- **声だけの話者**: 動画の最上位に `"voiceOnly": ["metan"]` と書くと、そのキャラは一度も画面に出ず、テンプレートの枠も使わない（空いた枠はほかの話者が使う。4人の並び・描ける人数にも数えない）。声と字幕は普段どおり。あとから `update_project_settings` の `voiceOnly` で変えられる（`null` か `[]` で外す）。`voiceOnly` のキャラを `stage`・`action`・`camera` の `target` に書く、`offstage` の行の話者をその行の `action`・`camera` の対象にするのは `400 validation_error`。声だけの行の `cameraMode:"dynamic"` は寄らない
- **立ち位置**（任意。文字列と混ぜてよい）: `x` はキャラの横の中心（画面の幅の %、0〜100。50 が真ん中）、`y` は枠の位置から下へずらす量（画面の高さの %、-50〜50）、`scale` は枠に対する大きさ（0.5〜2。東北・自作テンプレートは頭の高さを保つ、ゆっくりは下端を保つ）、`facing` は顔の向き（`left`/`right`。省くと `x` から画面の中央の方を向く）。書かなかった項目は枠のまま。次に `stage` を書いた行で、文字列で書いたキャラ・並びに無いのに話したキャラは枠に戻る（保つなら同じオブジェクトをもう一度書く）。位置が変わると約0.3秒で動く。位置を書いたキャラは4人の並び・素材の寄せに従わない（素材の枠と顔が重ならない `x` を選ぶ）。1人で真ん中に寄せるのは自動ではない（`x:50` と書く）。**カメラで真ん中に大きく映したいだけなら立ち位置は動かさず、行の `camera` の `target` で寄る**（`{"target":"zundamon","zoom":2}`。skill.md の「行ごとのカメラ」）
- `fadeBlack` は背景を変えない行でも暗転する（時間が飛ぶ所に）。`dissolve`・`cut` は背景か `backgroundMotion` が変わる行だけ
- **キャラの動き `action`**: 立ち絵の全体を動かすので、組み込み・自作（PNG・PSD）・ゆっくりのどれにも効く（口パク・表情・ポーズは続く）。
  `jump` 跳ぶ（約0.8秒・驚き・大喜び）/ `hop` ぴょんぴょん2回（約0.6秒。**同じ行の `stage` で立ち位置が変わるなら跳ねながら移る**。1回約0.3秒で2〜4回）/
  `shake` 震える（約0.6秒・怒り・怖さ）/ `bow` 顔の向きへお辞儀（約1秒・お礼・あいさつ）/ `spin` 振り向く（約0.5秒。同じ行で `facing` が変わればその向きへ、変わらなければ一回り）/
  `fall` ずっこける（後ろへ傾いて沈み、行の終わりまでに起き上がる。1.3〜3秒・ツッコミ・オチ）/ `bounce` はしゃぐ（3回弾んで左右に揺れる。約0.75秒）。
  target に書けるのは台本で話して画面に出るキャラだけ（ほかは `400 validation_error`・`invalidAction`）。動き出すのは行の音声の頭（アイキャッチの後・登場しきってから）。
  **盛り上がり・驚き・オチ・あいさつに。毎行には付けない**（5〜10行に1回くらい）
- `eyecatch` は**その行の音声の前に1.8秒の無音を足して**出す。台詞とは重ならないが、**動画が1.8秒ずつ長くなり、本番 MP4 のクレジット（動画1分につき1）にも入る**。大きな区切りに2〜4回まで

```json
{"title":"お金の基本","script":[
  {"speaker":"zundamon","text":"今日はお金の話をするのだ。","stage":["zundamon","anko"],
   "backgroundMotion":"zoomIn","eyecatch":{"title":"お金の基本","subtitle":"まずはここから"},"chapter":"お金の基本"},
  {"speaker":"anko","text":"今日はゲストがいるのだ。","action":"bounce"},
  {"speaker":"metan","text":"四国めたんよ。よろしくね。","stage":["zundamon","anko","metan"]},
  {"speaker":"zundamon","text":"また来てほしいのだ。","stage":["zundamon","anko"],"action":{"type":"bow","target":"metan"}},
  {"speaker":"zundamon","text":"ここからはひとりで話すのだ。","stage":[{"id":"zundamon","x":50}]},
  {"speaker":"anko","text":"戻ってきたのだ。","stage":[{"id":"zundamon","x":82,"facing":"left"},{"id":"anko","x":18,"facing":"right"}]},
  {"speaker":"anko","text":"外に出てみるのだ。","backgroundImageUrl":"https://example.com/forest.jpg",
   "backgroundMotion":"panRight","transition":"fadeBlack"},
  {"speaker":"zundamon","text":"次の章なのだ。","eyecatch":"今夜からできる対策","chapter":"今夜からできる対策"}
]}
```

## 知っておくこと（できないこと）

- 1本の動画に出せる人数はテンプレートのキャラの枠まで（動画全体の話者で数える。声だけの話者は数えない）: `tohoku-ahiru-talk`（とその複製）は4人、`yukkuri-talk` は2人。超えた話者は声と字幕だけ（位置を書いても出ない）。舞台にいない2人が1つの枠を交代で使うことはできない
- 位置を書かないキャラは枠の位置に立つ（テンプレートごと変えるなら `update_template_layout`）。重なり順（どちらが手前か）は枠で決まる
- `story-talk` では `stage`（立ち位置も）は効かない
- 背景の動きは画像の背景だけ（動画の背景は動かない）。`cameraMode:"dynamic"`（話者への寄り）とは別物で、重ねてよい
- 登場・退場・移動の速さ（約0.3秒）、アイキャッチの長さ（1.8秒）と見た目、暗転の長さ、動き（`action`）の大きさ・速さは変えられない。手足だけを動かすのは `pose`（腕）。`story-talk` では `action` も効かない
- 詳しくは skill.md の「場面の演出」
